# Hello-World

Python from the very first `print` to classes, modules and packages, one concept per file. I wrote these as teaching material for the basics-of-Python classes I took as an Academy Instructor at BRAC University Computer Club, so every file is meant to be read top to bottom by someone who has never programmed before.

## What's inside

| Path | What it covers |
|---|---|
| `Codes/01 - Printing.py` to `Codes/23 - Truthy-Falsy.py` | 23 lessons in teaching order: printing, input and type conversion, strings, arithmetic, `if`, `while`, `for`, 1D and 2D lists, list methods, tuples, unpacking, dictionaries, functions, exception handling, classes, inheritance, modules, packages, random numbers, files and directories, sets, truthy and falsy values |
| `Codes/Challenges/` | 17 small practice problems to try after the lessons |
| `Codes/converters.py`, `Codes/Shop/` | The module and the package that lessons 18 and 19 import |

## Running a lesson

Open the repo folder in PyCharm or VS Code and run any file with Python 3. Lessons 18 and 19 import `Codes.converters` and `Codes.Shop`, so they need the repo root on the Python path, which an IDE sets up for you.

For a small game built only from these basics, see [CERO](https://github.com/Muntaha-Islam0019/CERO).
